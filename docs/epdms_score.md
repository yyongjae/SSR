## 0. 수식 없이 읽는 직관적 설명: 무엇을 차용했고, 무엇을 우리가 새로 만들었나?

우리 모델은 1단계에서 뽑은 16개 기본 경로를 2단계에서 가속·감속·차선변경 등으로 변형해 **총 96개의 후보 궤적**을 만듭니다. 이 96개 중 최종 1개를 고를 때 쓰는 채점 기준이 **Option A / B / A+ / B+**입니다.

채점 기준에 들어가는 요소들을 **"기존 공통 방식 / 선행 논문에서 차용한 것 / 우리가 새로 만든 것"**으로 구분하면 다음과 같습니다.

### ① 주변 환경과의 안전성 및 주행 효율 (`충돌 없음 NC`, `도로 안쪽 주행 DAC`, `진행 거리 EP`, `충돌 여유 시간 TTC`)
* **출처**: 모든 최신 2단계 E2E 논문(`DrivoR`, `GTRS`, `DriveSuprim`, `Hydra-MDP++` 등)의 공통 방식 + 우리 2단계 네트워크 예측값
* **설명**: 내 차가 주변 차와 부딪힐지, 도로 밖으로 나갈지, 얼마나 앞으로 잘 나아갈지는 주변 환경을 봐야만 알 수 있습니다. 따라서 이 4가지는 우리 2단계 신경망 헤드가 예측한 점수를 그대로 사용합니다.

### ② 승차감(`HC`)과 이전 주행과의 연속성(`EC`)
* **출처**: **`DriveSuprim` 및 `GTRS`에서 차용** (물리량 직접 계산 방식)
* **설명**:
  - 핸들을 너무 급하게 꺾거나 급가속/급브레이크를 밟지 않는지(**승차감 `HC`**), 그리고 0.5초 전 프레임에 내가 실제로 선택했던 궤적과 지금 고르려는 후보 궤적이 갑자기 확 튀지 않는지(**연속성 `EC`**)는 주변 차량이나 외부 지도와 상관없이 **내 후보 궤적의 좌표만 보면 100% 정확하게 계산**할 수 있습니다.
  - 따라서 굳이 오차가 있는 신경망 예측값을 쓰지 않고, `DriveSuprim`과 `GTRS`가 한 것처럼 후보 궤적의 속도·가속도·좌표 차이로 직접 계산해서 점수로 반영했습니다.

### ③ 1단계 대표 경로와의 일관성 (`Option A`에는 없고, **`Option B`에 들어간 우리만의 아이디어**)
* **출처**: **우리 2단계 모델 구조에 맞춰 우리가 새롭게 정의한 방식 (`Stage-1 Corridor Consistency, CC`)**
* **설명**:
  - 원래 고민이었던 부분은 **"차선 유지(`LK`) 점수를 어떻게 할 것인가?"**였습니다. 우리 신경망에는 차선 유지 예측 헤드가 없고, 그렇다고 평가용 정답 지도(`metric_cache`의 `centerline`)를 가져다 쓰면 명백한 치팅이 됩니다.
  - 그래서 **Option A**는 이 항목을 아예 빼버린 버전입니다.
  - 반면 **Option B**는 **우리가 새로 고안한 방식**입니다. 우리 1단계 모델이 가장 자신 있게 뽑은 **'1등 기본 궤적'**은 이미 카메라를 보고 차선을 따라가도록 잘 학습된 경로입니다. 따라서 외부 지도를 쓰는 대신, **"2단계에서 속도를 바꾸거나 옆으로 살짝 변형한 96개 후보들이 1단계 1등 기본 궤적의 진행 통로(Corridor)에서 너무 엉뚱하게 벗어나지 않았는가?"(경로 일관성)**를 계산해 점수로 넣어준 것입니다.
  - 이렇게 하면 외부 정답 지도를 전혀 쓰지 않고 내 모델의 출력만 100% 사용하므로 치팅 논란이 없으면서도, 2단계 변형 궤적이 엉뚱한 방향으로 튀는 것을 막아줍니다.

### ④ 안전 점수(`충돌 없음 NC`, `도로 안쪽 주행 DAC`) 비중 강화 (**`Option B`에서 `Option B+`로 갈 때 딱 하나 추가된 것**)
* **출처**: **`DrivoR`, `GTRS`, `Hydra-MDP++`에서 차용** (위험 회피 안전 가중치 $w_{\text{safe}}$)
* **설명**:
  - 원래 EPDMS 평가에서는 진행 거리나 승차감이 조금 부족하면 총점이 몇 점 깎이는 데 그치지만, **충돌(`NC`)이나 도로 이탈(`DAC`)은 한 번이라도 발생하면 그 시나리오 전체 점수가 무조건 0점**이 됩니다.
  - 기존 **Option B**는 원래 공식대로 안전 점수와 나머지 점수들을 똑같이 1:1 비중으로 반영했습니다.
  - 반면 **`DrivoR`, `GTRS`, `Hydra-MDP++`** 같은 논문들은 **"어차피 충돌하거나 도로 밖으로 나가면 0점이 되니, 궤적을 고를 때는 안전 점수(`NC`, `DAC`)의 중요도를 원래 공식보다 1.3배~1.5배 더 무겁게 반영하자"**는 방식을 씁니다.
  - **Option B+**는 우리가 만든 **Option B에다가 이 아이디어("안전 점수 비중을 1.33배~1.50배로 높여서 조금이라도 위험한 궤적은 더 강하게 걸러내자") 딱 하나만 얹은 것**입니다 (`Option A+` 역시 `Option A`에 이 안전 비중만 똑같이 적용한 것입니다).

## 2. 왜 기존 `v7_default` 수식은 `navhard`에서 점수가 낮았는가?

기존 [`select.py`](file:///workspace/yongjae/SSR-v7/navsim/agents/para_ssr/ck/select.py)의 기본 선택기(`v7_default_b0.75`)는 아래 수식을 사용했습니다:
$$S_{\text{v7}}(k, v) = 0.25\,S_{\text{stage1}}(k) + 0.75\Big(0.1\log \text{IM}_k + \mathbf{0.5}\log \widehat{\text{NC}}_{k,v} + \mathbf{0.5}\log \widehat{\text{DAC}}_{k,v} + \log(5\,\widehat{\text{TTC}}_{k,v} + 2\,\widehat{\text{C}}_{k,v} + 5\,\widehat{\text{EP}}_{k,v})\Big)$$

이 수식에는 두 가지 구조적 한계가 있었습니다:
1. **안전 게이트(`NC, DAC`) 가중치 반감 (`0.5` vs 공식 `1.0` 이상)**: 공식 EPDMS에서 곱셈 페널티($\text{NC} \times \text{DAC}$)로 작동하는 치명적 안전 지표를 $0.5$로 줄여, `navhard`의 좁은 도로나 장애물 구간에서 위험한 가속 변형을 과도하게 선택했습니다.
2. **프레임 간 궤적 일관성(`EC`, Extended Comfort) 부재**: Stage 2의 96개 변형 후보($a_{-1.0}, a_{+0.5}, l_{\pm 0.5}$)를 매 프레임 독립적으로 고르다 보니, 직전 프레임($t-1$)에 자차가 선택한 계획 궤적 $\tau^{*(t-1)}$과 반대 방향의 변형을 골라 `navhard` `EC`가 **`43.23%`**까지 급락했습니다.

## 3. 제안 방법론: 수학적 정식화 (Option A / A+ & Option B / B+)

### ✅ Option A & Option A+ (`LK`-Free 정석 수식): **Hierarchical Critic + Ego-Kinematic Comfort Selection**

후보 궤적 $\tau_{k,v}$ ($k \in \{0,\dots,15\}, v \in \{0,\dots,5\}$)에 대하여 최종 선택 점수 $S_{\text{A}}(k, v)$를 다음과 같이 정의합니다:

$$S_{\text{A}}(k, v) = (1 - \beta)\,S_{\text{stage1}}(k) + \beta\Big(w_{\text{safe}}\big(\log \widehat{\text{NC}}_{k,v} + \log \widehat{\text{DAC}}_{k,v}\big) + \log\big(5\,\widehat{\text{EP}}_{k,v} + 5\,\widehat{\text{TTC}}_{k,v} + 2\,\text{HC}(\tau_{k,v}) + 2\,\text{EC}(\tau_{k,v}^{(t)}, \tau^{*(t-1)})\big)\Big)$$

- **`Option A` (기본형)**: $\beta = 0.75, w_{\text{safe}} = 1.00$ (`ep20`: `navtest` **`92.27%`**, `navhard` **`46.16%`**)
- **`Option A+` (안전 게이트 강화형)**: $\beta = 0.75, w_{\text{safe}} = 1.50$ (`ep20`: `navtest` **`92.31%`**, `navhard` **`46.92%`**)

---

### ✅ Option B & Option B+ (Corridor-Consistent 수식): **Hierarchical Critic + Stage-1 Corridor Consistency ($\text{CC}$)**

$$S_{\text{B}}(k, v) = (1 - \beta)\,S_{\text{stage1}}(k) + \beta\Big(w_{\text{safe}}\big(\log \widehat{\text{NC}}_{k,v} + \log \widehat{\text{DAC}}_{k,v}\big) + \log\big(5\,\widehat{\text{EP}}_{k,v} + 5\,\widehat{\text{TTC}}_{k,v} + 2\,\text{HC}(\tau_{k,v}) + 2\,\text{CC}(\tau_{k,v}, \tau_{0,0}) + 2\,\text{EC}(\tau_{k,v}^{(t)}, \tau^{*(t-1)})\big)\Big)$$

- **$\text{CC}(\tau_{k,v}, \tau_{0,0}) \in \{0, 1\}$ (Stage-1 Reference Corridor Consistency)**:
  $$\text{CC}(\tau_{k,v}, \tau_{0,0}) = \mathbb{I}\!\left[\max_{\Delta t \text{ window of } 2.0\text{s}} \min_{t \in \Delta t} \text{dist}\big(\tau_{k,v}(t), \tau_{0,0}\big) \le 0.5\text{m}\right]$$
- **`Option B` (기본형)**: $\beta = 0.75, w_{\text{safe}} = 1.00$ (`ep20`: `navtest` **`92.23%`**, `navhard` **`46.41%`**)
- **`Option B+` (안전 게이트 강화형)**:
  - **$\beta = 0.75, w_{\text{safe}} = 1.33$**: `ep20` `navtest` **`92.26%`** / `navhard` **`47.09%`** (`S1 85.11% / S2 55.37%`)
  - **$\beta = 0.75, w_{\text{safe}} = 1.50$**: `ep20` `navtest` **`92.28%`** / `navhard` **`47.23%`** (`S1 85.29% / S2 55.67%`)
  - **$\beta = 0.80, w_{\text{safe}} = 1.33$**: `ep20` `navtest` **`92.34%`** / `navhard` **`46.91%`** (`S1 85.23% / S2 55.39%`)
  - **$\beta = 0.80, w_{\text{safe}} = 1.50$**: `ep20` `navtest` **`92.36%`** / `navhard` **`46.86%`** (`S1 85.24% / S2 55.44%`)
