## 0. 요약

| 질문 | 답 |
|---|---|
| E2는 E0보다 나은가? | **예.** navtest PDMS **86.15 vs 84.87, +1.28 [+0.74, +1.86]**. 충돌·도로 이탈·TTC·진행 모두 개선됐다 |
| 그중 KD의 몫은? | **아직 모른다.** E2 − E0에는 교정기 + GT 벌점(구조 보완)과 KD가 섞여 있다. KD만 없는 **E1**이 필요하다 |
| PARA-SSR 본체(planner)가 나빠졌나? | **아니다.** E2 초안 τ0 − E0 = −0.21 [−0.85, +0.41], 유의하지 않다 |
| teacher 교정기는 실제 E2E 초안에서도 믿을 만한가? | **예.** E0 초안에 사후 적용하면 R_T **+2.04**, R_M **+1.94**. 장면을 안 보는 R_none은 −0.10으로 효과가 없다 |
| 왜 E2(86.15)는 E0 + R_T(86.91)보다 낮은가? | 차이 0.76 중 **약 85%(0.65)는 같은 초안에서도 student 교정기가 teacher보다 덜 고치기 때문**이다. 방향은 맞지만 크기가 작다. 초안 차이는 0.11(유의하지 않음), 평가 경로 차이는 약 0.015(최대 약 0.03)다 |
| 덜 고치는 이유는? | 유력 후보 두 가지(인과는 미검증). ① **두 teacher와의 L1을 각각 걸고 평균하는 KD 방식:** teacher가 엇갈리면 "안 고침" 쪽이 최적이 된다. ② **학습 장면의 E2 초안은 고칠 일이 적었다** |
| 다음은? | (1) 학습 없이 교정 배율 확인(held-out에서), (2) KD target을 "두 teacher 교정의 평균" 또는 채널별 teacher로 변경, (3) E1 |

**주의 (navtest 사용):**
- 이 문서의 분석은 대부분 navtest에서 한 서술적 분석이다.
- 여기서 나온 수치로 다음 설계(배율 k, KD 형태 등)를 **navtest에서 고르면 과적합**이 된다.
- 다음 선택은 navtrain의 held-out 로그에서 하고, navtest는 최종 확인에만 쓴다.

## 1. 무엇을 평가했나

### 1-1. 비교 대상

| 이름 | 무엇 | 학습 |
|---|---|---|
| **E0** | 기존 PARA-SSR v1 (`interaction_final`) | 30 epoch, GPU 2장 |
| **E2 (τ_final)** | PARA-SSR + student 교정기. **최종 출력 = 교정 후 궤적** | 30 epoch, E0 레시피(유효 배치 128 동일. E2는 GPU 4장 × accumulate 8, E0는 GPU 2장 × accumulate 16) + GT 벌점 + KD(R_T, R_M) |
| **E2 초안 (τ0)** | 같은 E2 모델에서 **교정 전** planner 출력 | – |
| E0 + R_T / R_M / R_none | E0의 navtest 궤적에 stage T 교정기(고정)를 **사후 적용** | 추가 학습 없음. teacher 조감도(LiDAR·위성)를 테스트 때도 쓰므로 **배포 불가능한 참고치** |

- **E2 설정의 요점** (규칙 파일 STAGE E REVISION 3)
  - 장면당 초안 1개. epoch 0–4는 GT 교란 초안만, 이후는 GT 교란과 E2 초안을 반반 섞는다.
  - KD는 디코딩된 교정량 12개에 대한 L1이다. 두 teacher 각각과의 L1을 구해 평균한다(teacher 값을 먼저 평균하는 것이 아니다, §4-6).
  - GT 벌점과 KD의 크기를 EMA 기준으로 r:1로 맞춘다(KD 가중치 = r × EMA(GT 벌점) / EMA(KD), 상한 100). r은 epoch 0–5에 걸쳐 0에서 1로 올린다.
  - 조감도 기울기 배율은 1.0이고, planner로는 기울기를 차단한다.

### 1-2. 평가 설정
- **데이터:** navtest 12,146장면 전체(136개 주행 기록).
- **채점:** 공식 PDMS 채점. E0과 **같은 평가 파이프라인과 채점기 버전**이다. config를 줄 단위로 대조했다.
- **checkpoint:** epoch 29(마지막). E0과 같은 관례다.
- **통계:** 장면 짝지은 비교, 주행 기록 단위 bootstrap(10,000회) 95% 신뢰구간. seed는 1개라 **학습 편차는 반영되지 않는다.**
- **사전 등록:** 평가 방식은 결과를 보기 전에 규칙 파일("STAGE E — E2 EVALUATION SPEC")에 기록했다. E2 − E1 판정 규칙은 아직 정하지 않았다(E1 평가 전에 확정).
- **독립 검증:** 저장된 장면별 원자료에서 §2(도시별 제외)와 §3-1의 대표 수치를 다시 계산해 일치를 확인했다(`refiner_T/stageE_eval/verify.md`). 도시별 분할, 교정 빈도, §4 이후의 진단 수치는 그 검증 범위 밖이다.

## 3. 사후 실험: E0 초안에 teacher 교정기 적용

**목적:** teacher 교정기는 stage T에서 사람 궤적 교란 초안으로만 학습·평가됐다. 실제 E2E 초안도 잘 고치는지 확인한다. 잘 고친다면 KD target으로 믿을 만하다는 뜻이다.

**방법**
- E0의 navtest 궤적(장면당 1개)에 run 4의 R_T, R_M, R_none을 적용했다. run 3의 R_T도 참고로 넣었다.
- 교정기는 추가 학습 없이 고정하고, 교정은 항상 적용한다(θ=0).
- 모두 공식 `pdm_score`와 비트 단위로 같은 stage T batched 채점기로 채점했다.

### 3-1. 결과

| | PDMS | E0 대비 [95% CI] | 고친 실패 / 새 실패 |
|---|---|---|---|
| E0 | 84.88 | – | – |
| **E0 + R_T (BEVFusion)** | **86.91** | **+2.04 [+1.62, +2.49]** | 307 / 39 |
| **E0 + R_M (ReSMap)** | **86.81** | **+1.94 [+1.44, +2.48]** | 300 / 49 |
| E0 + R_none (장면 없음) | 84.78 | −0.10 [−0.22, +0.02] | 28 / 35 |
| E0 + R_T (run 3, 참고) | 86.35 | +1.47 [+1.16, +1.82] | 222 / 23 |

- E0 84.88은 궤적 파일을 stage T 채점기로 채점한 값이다. 공식 CSV의 84.87과 0.007 차이가 나며, 모든 조건이 같은 궤적에서 출발하므로 비교에는 영향이 없다.

### 3-2. 해석
- **teacher 교정기는 실제 E2E 초안도 잘 고친다.** 고친 실패가 새 실패보다 6–8배 많다.
- **teacher 정보가 핵심이다.**
  - R_T − R_none = +2.13, R_M − R_none = +2.03이다.
  - stage T 합성(교란) 초안에서 R_none은 +5.9점이었다(run 3 R_none, navtest. run 4 R_none의 stage T 값은 없다). 실제 초안에서는 run 4 R_none이 효과가 없었다. stage T에서 R_none의 점수가 "사람 궤적을 민 모양" 단서에서 나왔다는 해석과 부합한다.
- **두 teacher가 잘 고치는 영역이 다르다.**

| | NC | DAC | TTC | PDMS |
|---|---|---|---|---|
| R_T − E0 | **+0.55** | +1.68 | **+0.77** | +2.04 |
| R_M − E0 | +0.13 | **+2.03** | +0.29 | +1.94 |
| R_T − R_M | +0.42 [+0.22, +0.63] | −0.35 [−0.64, −0.08] | +0.48 | +0.10 [−0.22, +0.42] (유의하지 않음) |

  → 검출 teacher(R_T)는 충돌·TTC에, 지도 teacher(R_M)는 도로 이탈에 강하다. **상호 보완적이다.**
- **이득의 출처**
  - E0가 실패한 1,523장면: R_T +18.2점, R_M +18.0점
  - 이미 괜찮은 장면: R_T −0.28점, R_M −0.37점. 교정기가 거의 모든 궤적(약 95%)을 조금씩 고치면서 진행 점수를 잃는다.
- **도시별 (R_T − E0):** Singapore +4.15, Pittsburgh +2.09, Boston +1.79, Las Vegas +1.23. 모든 도시에서 양수다.
- **교정 빈도**

| | 감속한 장면 | 4초에 0.5 m 넘게 짧아짐 | 옆 이동 > 0.1 m | 옆 이동 > 0.5 m |
|---|---|---|---|---|
| R_T | 5.4% | 3.2% | 13.5% | 3.5% |
| R_M | 3.2% | 1.9% | 14.9% | 4.3% |
| R_none | 1.4% | 0.5% | 4.7% | 0.3% |

## 4. 왜 E2는 E0 + teacher보다 낮은가

### 4-1. 차이의 구조
E0 + R_T(86.91)와 E2(86.15)는 두 가지가 동시에 다르다.

| | 고치는 대상 (초안) | 고치는 주체 (교정기) |
|---|---|---|
| E0 + R_T | E0 초안 | teacher 교정기 (LiDAR 조감도, 테스트 때도 사용) |
| E2 | E2 초안 | student 교정기 (카메라 조감도) |

그래서 **E2 자신의 초안에 teacher 교정기를 적용**해, 같은 초안 위에서 student와 teacher를 직접 비교했다.

### 4-2. 같은 초안(E2 τ0) 위에서의 비교

| E2 초안 + | PDMS | E2(student) 대비 | 고친 실패 / 새 실패 (vs E2 초안) |
|---|---|---|---|
| (교정 없음) | 84.66 | −1.50 | – |
| **student (= E2)** | **86.15** | – | **211 / 16** |
| R_T | 86.80 | +0.65 [+0.35, +0.94] | 323 / 42 |
| R_M | 86.75 | +0.60 [+0.26, +0.96] | 317 / 45 |
| R_T (run 3) | 86.53 | +0.38 [+0.12, +0.62] | 274 / 27 |
| R_none | 84.75 | −1.40 | 36 / 18 |

- student는 R_T 개선폭(+2.14)의 **70%**, 고친 실패 수의 **65%**를 달성했다.
- 대신 **새 실패는 16건으로 teacher(42–45건)보다 훨씬 적다.** 보수적인 교정기다.

### 4-3. 차이 0.76점의 분해

| 요인 | 점수 [95% CI] | 몫 |
|---|---|---|
| 전체 차이: (E0 + R_T) − E2 | +0.76 [+0.24, +1.27] | 100% |
| **교정기 차이:** 같은 초안에서 R_T − student | **+0.65 [+0.35, +0.94]** | **약 85%** (CI 43–233%) |
| 초안 차이: (E0 + R_T) − (E2 초안 + R_T) | +0.11 [−0.38, +0.61] | 약 15% (유의하지 않음) |
| 평가 경로 차이 (채점기, ego 입력, 정밀도 등) | 약 0.015 (최대 약 0.03) | 약 2% (최대 약 4%) |

- R_M 기준으로도 같다. 차이 0.66 = 교정기 0.60(90%) + 초안 0.06.
- 몫의 신뢰구간이 넓은 이유는 전체 차이 자체가 작기 때문이다(하한 0.24).
- **epoch 28 checkpoint로 해도 차이가 0.74**라서, checkpoint 우연은 아니다.

### 4-4. 가설별 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| **H1. student 교정기가 같은 초안에서 teacher보다 약하다** | **지지 (주원인)** | 4-2 표. 교정기 차이 0.65 |
| H2. E2 초안이 더 나쁘거나 고치기 어렵다 | 불지지 | E2 초안 − E0 = −0.22 [−0.86, +0.39] (E0 궤적 파일 채점 기준. 공식 CSV 기준 −0.21, 유의하지 않음). teacher는 E2 초안에서 점추정상 조금 더 개선한다(+2.14 vs +2.04, 차이 +0.11 [−0.24, +0.47], 유의하지 않음) |
| **H3. student가 덜 고친다 (크기)** | **지지 (H1의 메커니즘)** | 아래 4-5 |
| H4. student가 반대 방향으로 고친다 | 기각 | 반대 방향 1.4%. 둘 다 움직일 때 방향 일치도(cosine) 0.92 |
| **H5. 두 teacher L1 평균 KD라서 엇갈리면 약해진다** | **부분 지지 (유력, 인과 미검증)** | 아래 4-6 |
| **H6. 학습 초안 구성 때문에 실제 초안에서 덜 고친다** | **부분 지지** | 아래 4-7 |
| H7. student 조감도(카메라)의 정보 부족 | 약함 | teacher만 고친 충돌의 77%, TTC의 62%에서 E2도 원인 물체를 검출했다. 검출 여부에 따른 student 교정률 차이는 관찰되지 않았다(NC −0.19 [−0.52, +0.22], TTC −0.02 [−0.30, +0.26]. 표본이 작아 0.2 정도의 효과는 배제 못 함). 몫 0.13 [−0.04, +0.31] |
| H8. 평가 경로 차이 | 기각 | 모든 항목이 0 또는 약 0.01 |
| H9. seed 잡음 | 미측정 | 교정기 몫이 잡음이려면 seed 편차가 0.23점 이상이어야 한다. 참고로 NAVSIM TransFuser 3-seed 표준편차는 0.56(모델 전체) |
| 원시 감속값 포화 (`zdead`) | 원인 아님 | teacher가 더 포화돼 있다(83–88% vs student 74%). 포화 여부와 놓친 교정률(0.55 vs 0.53)이 무관하다 |

### 4-5. 메커니즘: student는 "같은 방향으로, 작게" 고친다

| 같은 초안(E2 τ0)에서 | student | R_T | R_M |
|---|---|---|---|
| 감속하는 장면 비율 | **2.2%** | 5.0% | 3.1% |
| 옆 이동 > 0.1 m 비율 | **7.9%** | 13.0% | 13.7% |

- student 교정량을 teacher 평균에 회귀하면 **기울기는 감속 0.25, 옆 이동 0.50**이다. 즉 teacher가 1만큼 고칠 때 student는 감속 0.25, 옆 이동 0.5만큼 고친다.
- R_T가 감속하는 장면 중 student도 감속하는 비율은 28%다.
- navtest에서 student 교정과 teacher 교정의 거리(KD loss)는 0.0230이다. "아무것도 안 고침"(0.0253)보다 9% 가까울 뿐이다.

### 4-6. 유력 원인 ①: KD 방식 (두 teacher와의 L1을 각각 걸고 평균)
- 현재 KD = ½|s − t_T| + ½|s − t_M|이다. 이 식은 **student 값이 두 teacher 값 사이 어디에 있든 똑같이 최소**다.
- 두 teacher가 자주 엇갈린다.
  - 둘 다 감속하는 장면은 1.4%, 한쪽만 감속하는 장면은 5.3%다.
  - 두 teacher 교정의 평균 차이(0.033)가 각 teacher의 교정 크기(0.027, 0.024)보다 크다.
- 한 teacher가 "안 고침"이면 KD에는 student를 고치는 쪽으로 미는 힘이 없다. 실제로 두 teacher가 엇갈리는 원소(|T − M| > 0.02)에서 student 값의 **62%가 두 teacher 사이, 23%가 약한 쪽 바깥**에 있고, 위치 중앙값은 약한 쪽 끝이다.
- **대안 target의 사후 상한 (서술용)**
  - 두 teacher 교정의 **평균(MID)**을 E2 초안에 적용: **87.09**. E2보다 +0.94 [+0.65, +1.24], R_T 단독보다 +0.30 높다.
  - teacher 한쪽만 고치는 장면에서 MID는 E2보다 +0.32 [+0.17, +0.47] 높다.
  - 채널별 조합(미검증)은 부분 결과만 있다. student에 R_M의 옆 이동만 넣으면 +0.60, R_T의 감속만 넣으면 +0.26이었다.

### 4-7. 유력 원인 ②: 학습 초안 구성
- 학습 장면에서 E2 초안(τ0)은 **학습 데이터라 navtest보다 훨씬 덜 틀린다.** E0 기준 충돌 실패율이 학습 장면 0.70%, navtest 2.30%다.
- student/teacher 감속 비율
  - 교란 초안: 1.06 (teacher만큼 고침)
  - 학습 장면 τ0: **0.62**
  - navtest τ0: **0.55**
  - → 실제 초안에서 덜 고치는 습관이 **학습 때부터** 있었다. 학습과 평가 사이의 차이는 작다.
- 두 teacher가 모두 고치는 장면에서도 student는 "최소 교정"보다 0.18점 뒤처진다. KD 형태만으로는 다 설명되지 않는다.
- GT 벌점의 진행 항(가중치 2)이 감속 반대 방향으로 당기는 효과도 함께 작용할 수 있다(미검증).

## 7. 해석과 한계
1. **E2 − E0(+1.28)은 KD 효과가 아니다.** 교정기 구조와 GT 벌점의 효과가 섞여 있다. KD의 몫은 **E1(KD 없음)과 비교해야** 알 수 있다.
2. **teacher 교정기 자체는 실제 초안에서 강하다(+2.0).** KD target으로 쓸 만하다는 근거가 있다(seed 1개, navtest 서술적 결과). 문제는 student가 그것을 **충분히 따라 하지 못한다**는 점이다.
3. **"teacher가 상한선이 된다"는 우려와 반대 상황이다.** student는 teacher에 한참 못 미치게 약하게 따라 한다.
4. **seed 1개:** 모든 신뢰구간은 장면 표본 편차만 반영한다.
5. **navtest를 진단에 사용했다.** 이 문서의 수치로 다음 설계 값을 고르면 안 된다. §8의 선택은 held-out navtrain 로그에서 한다.
6. **E0 + R 참고치는 배포 불가능하다.** 테스트 때도 LiDAR·위성 조감도를 쓰기 때문이다. E2는 카메라만으로 그 이득(+2.04)의 약 63%를 얻었다.
