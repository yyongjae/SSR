## 독립 검증 (반박 시도 3개)

1. **재계산: 판정 스크립트 없이 원자료에서 다시 계산해도 모든 값이 일치한다.**
   - 두 arm의 초안 쌍, 유효 마스크, 원본 점수가 비트 단위로 같다.
   - PDMS 공식 `NC·DAC·DDC·(5EP + 5TTC + 2C)/12`와 오차 0이다.
   - 무효 초안 5,704개를 포함해도, 주행 기록마다 같은 가중치를 줘도 PASS다.
2. **견고성: θ, 초안 유형 하나 빼기, 모양 단서가 있는 유형(cv, lat, combined) 제외, OOF fold 0에서 모두 같은 방향이다.**
   - OOF fold 0: P1 +1.33, P2 +1.00이다.
   - lat 유형만 P2가 반대다(−1.07). run 2와 같은 모양 단서 효과다.
3. **타당성 감사: dev는 어떤 선택에도 쓰이지 않았다.**
   - 여유값, V2, m_ttc, θ 모두 train만 썼고, θ는 dev 예측 전에 고정됐다.
   - 두 arm 사이의 불공정 요소는 찾지 못했다.
   - dev를 세 번 본 것을 Bonferroni로 보정해도 P2는 [0.39, 1.20]으로 0보다 크다.

## 해석을 좁히는 발견 (중요)

1. **P2 효과는 거의 전부 Las Vegas에서 나온다.**
   - 순효과의 99.7%가 Las Vegas에서 나오고, Las Vegas의 P2는 +1.22다.
   - 나머지 세 도시를 합치면 P2는 +0.01 [−0.26, +0.30]이고, P1은 +1.31이다.
   - OOF fold 0에서도 같다. 순효과의 96%가 Las Vegas이고, 나머지 도시는 +0.10이다.
   - navtest의 도시 비율로 다시 가중하면 P2는 +0.46 [+0.22, +0.71]이다. PASS는 유지되지만 크기는 약 60%로 줄어든다.
   - P1(PDMS)은 모든 도시에서 양수다.
2. **dev는 기록(log) 단위로는 분리됐지만 주행(drive) 단위로는 분리되지 않았다.**
   - dev 295개 log 중 285개가 같은 날·같은 차량의 인접 구간을 train에 두고 있다(dev 토큰의 94%).
   - 주행 전체가 train에 없는 10개 log에서는 P1 +0.71 [−0.15, +1.31], P2 −0.25 [−1.31, +0.68]로 우위가 보이지 않는다.
   - 인접 구간이 train에 있는 log와 없는 log의 차이는 유의하다(P2 +1.10 [0.11, 2.26]).
   - 가능한 해석: R_T가 teacher feature에서 "장소별 단서"를 배워, 같은 주행의 이웃 구간에 적용했다. R_none은 이것을 할 수 없다.
   - 10개 log뿐이라 증명은 아니다. 하지만 일반화에 대한 가장 강한 위협이다.
3. **teacher가 dev 장면을 학습 때 봤다(in-sample).**
   - 현재 프레임 검출 recall은 dev 0.893, navtest 0.846으로 dev가 조금 더 좋다.
   - R_T의 우위가 teacher 검출이 완벽한 장면에 몰려 있지는 않다. 오히려 teacher가 물체를 많이 놓친 장면에서 크다.
4. **결과를 보고 내린 결정들 위에 선 결과다.**
   - PASS는 run 2의 dev 분해를 보고 추가한 TTC 대리 손실에 전적으로 의존한다.
   - 사전 규칙이 INCONCLUSIVE일 때 정한 조치는 seed 추가나 dev 확대였지만, 실제로는 학습 목표를 바꿨다.
5. **seed가 하나다.**
   - 두 arm에 똑같이 적용한 목표 변경 하나로 P2가 1.6 pp 움직였다. run 3 효과 크기의 두 배다.
   - 학습 편차는 측정하지 않았다.

## 결론

- 사전 규칙상 R_T는 PASS다.
- 다만 지금 증거로 말할 수 있는 것은 여기까지다.
  - "Las Vegas 중심의 navtrain 내부 dev에서, 같은 주행의 이웃 구간이 학습에 있는 조건에서, teacher BEV를 읽는 교정기가 더 잘 고친다."
  - PDMS 우위(P1)는 도시 전반에서 성립한다.
  - 충돌+TTC 우위(P2)는 Las Vegas와 주행 중첩 조건에 묶여 있다.
- 주행 단위로 분리된 데이터(navtest)에서 확인하기 전에는, "teacher의 장면 정보가 교정에 필요하다"는 주장을 확정할 수 없다.
