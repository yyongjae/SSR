Stage T pre-stated decision rule (written 2026-09-28, BEFORE any refiner result exists). Values marked [default] may be changed by the user only before the first dev evaluation.

Question: Is the teacher refiner (R_T: reads frozen BEVFusion 50x100 BEV) a better corrector than the same refiner without scene features (R_none)?
Data: dev = held-out navtrain logs (log-level split, city-stratified). Drafts = the dev draft bank (13 per token: human perturbations + constant-velocity), official PDM scoring (v1 fork, scorer equivalence-tested).
Inference rule per arm: apply correction iff p_g >= theta, else keep the ORIGINAL draft. theta and loss weights chosen by 5-fold log-level cross-fitting inside the TRAIN pool only, per arm, under the same budget.
Seeds: 3 per arm [default]. Statistics: log-cluster paired bootstrap (10,000), 95% CI, seed-averaged.

Primary endpoints (R_T - R_none), all at the progress budget: mean EP loss vs original drafts <= 0.5 points [default]:
 P1 official PDMS difference over all dev drafts.
 P2 total failures: NC and TTC failures (primary); DAC and DDC as non-inferiority (R_T not worse by more than 0.5 percentage points [default]).
 P3 new failures (any of NC, DAC, DDC, TTC, comfort on drafts that passed before): R_T not worse than R_none by more than 0.5 percentage points [default].
Sanity (must hold for the measurement to count): at least one arm improves PDMS over "no correction" with CI lower bound > 0.

Outcomes:
 PASS: P1 lower CI > 0 AND P2 (NC+TTC) lower CI > 0 AND P3 non-inferior  -> teacher refiner qualified as KD teacher; proceed to stage E (E1 vs E2).
 EQUIVALENT: P1 and P2 CIs inside +-0.2 PDMS points / +-0.5 pp [default] -> "under the current frozen-feature / refiner setting the teacher shows no correction advantage".
   This does NOT rule out benefits in E2E joint training (e.g. convergence); whether to run stage E is the user's decision.
 INCONCLUSIVE: neither -> add seeds / enlarge dev; no conclusion.
 WORSE: R_T significantly below R_none -> diagnose (adapter, normalisation, map information) before any conclusion.
Reported but not decisive: real-draft-like subsets (constant-velocity, L-const), family-wise results, R_GT-cur if added, surrogate-vs-official agreement (M8).
navtest is NOT used for this decision; it is used once for the final frozen report.
Interpretation limits (not blockers): the teacher was trained on all navtrain (teacher features are in-sample on train and dev pools); no student features are compared in stage T.
